# COEN 554 Personal Portfolio Website

## Project structure

- `index.html` — Home page
- `about.html` — About Me
- `education.html` — Educational Background
- `skills.html` — Technical Skills
- `projects.html` — Projects
- `hobbies.html` — Hobbies & Interests
- `cv.html` — Curriculum Vitae
- `contact.html` — Contact Me
- `assets/css/style.css` — Responsive CSS3 stylesheet
- `assets/images/` — Image placeholders
- `data/data.json` — Structured content data
- `cv/` — Put your actual PDF CV here

## Important

Replace all `[PLACEHOLDER]` values with your information.

Replace the SVG placeholders in `assets/images/` with your own images if desired.

The site intentionally contains no JavaScript. It uses HTML5, CSS3, JSON, and JSON-LD.

## Running locally

Open `index.html` in a browser. All pages use relative links, so the folder can also be hosted as a static website.

## Before submission

1. Replace personal placeholders.
2. Add your real profile/project images.
3. Add your PDF CV to `cv/` and update the link in `cv.html`.
4. Update `data/data.json`.
5. Validate all HTML/CSS.
6. Test every navigation link.
7. Test the layout on desktop and mobile.
8. Add your real deployment URL to the JSON-LD where indicated.
